# Friends League · eFootball 2027 Mobile

เว็บจัดทัวร์นาเมนต์ eFootball 2027 Mobile ระหว่างเพื่อน ๆ หน้าตาสไตล์ eFootball 2022 (น้ำเงิน + เหลือง)
บันทึกผล ดูตารางคะแนนสด จัดทีม 23 คน และเก็บสถิตินักเตะรายคน

**เปิดเว็บ:** https://jubfifa23.github.io/friends-league/

ผลการแข่งต้องกรอกเอง เพราะ Konami ไม่มี API สำหรับดึงผล Custom Tournament

## ทำอะไรได้บ้าง

- **หน้าแรก**: นัดถัดไปพร้อมนับถอยหลัง, การ์ดทีม 4 อันดับแรก (กรอบทอง/เงิน/ทองแดง), ดาวซัลโว และผลล่าสุด
- **ตารางคะแนน**: ตราทีม, ลูกศร ▲▼ บอกอันดับที่ขยับ และปุ่มแชร์ตารางเป็นรูป (ส่ง LINE ได้)
- **โปรแกรม/ผล**: จัดโปรแกรมพบกันหมดอัตโนมัติ (เลือกแบบเหย้า–เยือนได้), เลื่อนวัน/เวลา และกรอกผลโดยเลือกคนยิง/แอสซิสต์จากรายชื่อทีม
- **ผลงานนักเตะ**: หลังจบแต่ละนัด บันทึกได้ว่าใครลงเล่น ใส่คะแนน 0–10 และเลือกผู้เล่นยอดเยี่ยม (MOTM)
- **นักเตะ**: ตารางสถิติรายคน ได้แก่ นัดที่ลงเล่น ประตู แอสซิสต์ คะแนนเฉลี่ย MOTM ใบเหลือง และใบแดง
- **ทีม**: โปรไฟล์ทีม แสดงตัวจริง 11 คนบนสนามเป็นรูปการ์ดนักเตะ และรายชื่อครบ 23 คน พร้อมสถิติ
- **ข้อมูลนักเตะ**: กดที่นักเตะ (บนสนาม ในรายชื่อทีม หรือในแท็บนักเตะ) เพื่อดูการ์ดใบใหญ่ ระดับการ์ด OVR ตำแหน่ง สถิติรวม และผลงานรายนัด (คู่แข่ง ผล คะแนน ประตู แอสซิสต์ ใบ MOTM)
- **ข้อมูลออนไลน์ (Firebase)**: ทุกเครื่องเห็นข้อมูลเดียวกันแบบสด ล็อกอินและสิทธิ์ตรวจที่เซิร์ฟเวอร์ (ดูหัวข้อด้านล่าง)
- **Export / Import JSON**: สำรองข้อมูลลีก

### นักเตะ 23 คนต่อทีม

- ตัวจริงต้องมี **11 คนพอดี** และสำรอง **12 คน** ถ้าไม่ครบจะบันทึกไม่ได้
- ตำแหน่งใช้แบบ eFootball (GK, CB, LB, RB, DMF, CMF, AMF, LMF, RMF, LWF, RWF, SS, CF) สีป้าย: GK ส้ม · DF น้ำเงิน · MF เขียว · FW แดง
- **ประเภทการ์ด**: Epic / Big Time / Show Time / Highlight / Featured / POTW / Legendary
  - ลีกนี้**ไม่ใช้การ์ด Standard**
  - นักเตะที่ใส่ชื่อแล้วต้องเลือกประเภทการ์ดก่อนจึงจะบันทึกได้
- ใส่ค่าพลัง (OVR) ได้ระหว่าง 40–120 และวางลิงก์การ์ดจาก EFHUB ได้ ทั้งสองช่องไม่บังคับ

### แผนการเล่น

เลือกได้ 15 แผน: 4-4-2, 4-3-3, 4-3-2-1, 4-3-1-2, 4-2-3-1, 4-2-1-3, 4-1-4-1, 4-1-2-3, 3-4-3, 3-2-4-1, 3-2-3-2, 3-1-4-2, 5-3-2, 5-2-2-1, 5-2-1-2

- ผู้จัดการทีมหรือแอดมินเลือกแผนได้ในหน้าแก้รายชื่อนักเตะ แต่ละแผนมี 11 ช่อง และแต่ละช่องมีตำแหน่งแบบในเกม เช่น 4-2-3-1 = GK · LB CB CB RB · DMF DMF · LMF AMF RMF · CF
- แอปจัดตัวจริงลงช่องให้อัตโนมัติตามตำแหน่งที่ใกล้ที่สุด และสลับคนเองได้ ช่องที่ขึ้นสีแดงคือนักเตะเล่นนอกตำแหน่ง
- แสดงแผนบนสนามในโปรไฟล์ทีม บนการ์ดทีม และบนการ์ดนัดถัดไป
- ตอนกรอกผล บันทึกได้ว่าแต่ละทีมใช้แผนอะไรในนัดนั้น โปรไฟล์ทีมจะสรุปผลชนะ/เสมอ/แพ้แยกตามแผนให้

### รูปการ์ดนักเตะ

- ใส่รูปการ์ดได้คนละ 1 รูป เช่น รูปการ์ดที่แคปจากเกมหรือบันทึกจาก EFHUB (เฉพาะแอดมินและผู้จัดการของทีมนั้น) ทำได้ 2 ทาง:
  - **แตะนักเตะบนสนาม**ในโปรไฟล์ทีม (ส่วนตัวจริง 11 คน) → กด **ใส่รูปการ์ด** แล้วเลือกรูป แอปบันทึกให้ทันที เปลี่ยนหรือลบรูปได้ในหน้าเดียวกัน
  - ในหน้า **แก้รายชื่อนักเตะ**: กดช่อง **รูป** ในแถวของนักเตะแล้วเลือกรูป (ลบได้ด้วยปุ่ม ✕ สีแดงที่มุมรูป) เสร็จแล้วกด **บันทึกรายชื่อ**
- แอปย่อรูปเหลือกว้าง 200px (ประมาณ 25 KB ต่อรูป) ก่อนเก็บ ถ้าใช้รูปเดียวกันกับหลายคน แอปเก็บไว้แค่ชุดเดียว
- โปรไฟล์ทีม › **ตัวจริง 11 คน** สลับดูได้ 2 แบบ คือ **การ์ด** (วางรูปการ์ดบนสนามตามแผน) และ **รายชื่อ** นักเตะที่ยังไม่มีรูปจะแสดงเป็นการ์ดสีตามตำแหน่งแทน
- แตะการ์ดบนสนามเพื่อดูรูปขนาดใหญ่ พร้อมสถิติ นัด / ประตู / แอสซิสต์ / คะแนนเฉลี่ย / MOTM
- รูปเก็บบน Firebase ทุกเครื่องจึงเห็นรูปเดียวกัน (มีแคชในเบราว์เซอร์ด้วย IndexedDB) และรวมอยู่ในไฟล์ Export JSON ด้วย

### EFHUB

EFHUB (efhub.com) ไม่มี API สาธารณะ และป้องกันไม่ให้ระบบภายนอกดึงข้อมูล แอปนี้จึงไม่ดึงข้อมูลจาก EFHUB โดยตรง แต่ทำแบบนี้แทน:

- ปุ่ม 🔍 ข้างชื่อนักเตะ จะค้นหาการ์ดของคนนั้นใน efhub.com (ผ่าน Google) ในแท็บใหม่
- คัดลอกลิงก์หน้าการ์ด เช่น `https://efhub.com/players/12345` มาวางในช่องลิงก์
- ในโปรไฟล์ทีมจะมีไอคอน ↗ กดแล้วกลับไปดูการ์ดใน EFHUB ได้

## บทบาทและสิทธิ์

| บทบาท | ทำอะไรได้ |
|---|---|
| ผู้ชม (ไม่ล็อกอิน) | ดูทุกหน้า และ Export JSON |
| ผู้จัดการทีม (User) | แก้ชื่อทีม สีทีม และรายชื่อนักเตะของทีมตัวเอง (ตัวจริง/สำรอง ตำแหน่ง แผนการเล่น การ์ด OVR ลิงก์ EFHUB รูปการ์ด) |
| กรรมการ | กรอก/แก้ผลการแข่ง และผลงานนักเตะ |
| แอดมิน | ทำได้ทุกอย่าง: สร้างทีม จัดโปรแกรม เลื่อนวัน จัดการผู้ใช้ Import/รีเซ็ตข้อมูล และย้ายข้อมูลจากเครื่องขึ้นออนไลน์ |

- บัญชีแรกที่สร้างคือแอดมิน (เจ้าของลีก) แอดมินสร้างบัญชีให้ผู้จัดการทีมและกรรมการได้ในเมนูบัญชี › จัดการผู้ใช้ และเลือกได้ว่าใครดูแลทีมไหน
- ไม่มีการเก็บรหัสผ่านตัวจริง: โหมดออนไลน์รหัสผ่านอยู่ใน Firebase Authentication · โหมดเครื่องเดียวเก็บแค่ค่า hash (SHA-256 + salt)

## เริ่มใช้งาน (แอดมิน)

1. ตั้งค่า Firebase ตามหัวข้อด้านล่าง แล้วเปิดเว็บ → กด **ตั้งค่าแอดมิน** (ทำได้ครั้งเดียว คนแรกที่สร้างเป็นเจ้าของลีก)
2. ถ้าเคยกรอกข้อมูลไว้ในเบราว์เซอร์นี้: หน้าแรก → **ย้ายข้อมูลจากเครื่องนี้ขึ้นออนไลน์** · ไม่งั้นแท็บ **ทีมทั้งหมด** → **สร้างทีมใหม่**
3. เมนูบัญชี (รูปโปรไฟล์มุมขวาบน) → **จัดการผู้ใช้** → เพิ่มบัญชี **ผู้จัดการทีม** และเลือกทีมให้แต่ละคน
4. แท็บ **โปรแกรม/ผล** → **จัดโปรแกรมอัตโนมัติ**

## ข้อมูลออนไลน์ (Firebase)

เมื่อใส่ค่า Firebase ใน `config.js` แล้ว ทั้งลีกจะเก็บบน Cloud Firestore ของ Google ทุกเครื่องเห็นข้อมูลเดียวกันทันที และการล็อกอินตรวจที่เซิร์ฟเวอร์ ถ้าไม่ใส่ค่า แอปจะทำงานแบบเครื่องเดียว (ข้อมูลอยู่ในเบราว์เซอร์นั้น)

- ทุกคนเปิดเว็บแล้วเห็นตารางคะแนน โปรแกรม ผล นักเตะ และรูปการ์ดได้เลย ไม่ต้องล็อกอิน
- สิทธิ์ถูกตรวจที่เซิร์ฟเวอร์ตามไฟล์ `firestore.rules`: ผู้จัดการทีมแก้ได้แค่ทีมตัวเอง กรรมการแก้ได้แค่ผลการแข่ง และไม่มีใครตั้งตัวเองเป็นแอดมินได้
- **ตั้งค่าแอดมิน** ทำได้ครั้งเดียว คนแรกที่สร้างเป็นเจ้าของลีก ลดสิทธิ์หรือลบไม่ได้
- ใช้แพ็กเกจฟรี (Spark) พอสำหรับลีกเพื่อน ไม่ต้องผูกบัตร
- เน็ตหลุด: ยังดูข้อมูลล่าสุดในเครื่องได้ และสิ่งที่แก้จะส่งขึ้นเองเมื่อกลับมาออนไลน์

### ตั้งค่าครั้งแรก (เจ้าของลีกทำครั้งเดียว ประมาณ 10 นาที)

ค่าใน `config.js` ไม่ใช่รหัสลับ ทุกเว็บที่ใช้ Firebase แสดงค่านี้ในหน้าเว็บอยู่แล้ว ความปลอดภัยมาจากกฎในข้อ 5 และโดเมนในข้อ 3

1. เข้า https://console.firebase.google.com → **Create a project** (เช่น `friends-league`) → ปิด Google Analytics → **Create project**
2. **Build › Authentication** → **Get started** → แท็บ **Sign-in method** → **Email/Password** → เปิดสวิตช์อันแรก → **Save**
3. **Authentication › Settings › Authorized domains** → **Add domain** → `jubfifa23.github.io`
4. **Build › Firestore Database** → **Create database** → Location **asia-southeast1 (Singapore)** (เปลี่ยนทีหลังไม่ได้) → **Start in production mode**
5. **Firestore Database › Rules** → ลบของเดิม วางทั้งไฟล์ `firestore.rules` → **Publish**
6. ⚙ **Project settings › Your apps** → ไอคอน **`</>`** (Web) → ตั้งชื่อ → **Register app** → คัดลอกค่าใน `firebaseConfig`
7. ใส่ค่าใน `config.js` แล้ว commit + push ขึ้น GitHub → เปิดเว็บแล้วกด **ตั้งค่าแอดมิน** ทันที

### ย้ายข้อมูลที่เคยกรอกไว้ขึ้นออนไลน์

ถ้าเคยใช้แบบเครื่องเดียวมาก่อน ข้อมูลจะอยู่ในเบราว์เซอร์ที่ใช้กรอก (อย่าล้างข้อมูลเบราว์เซอร์นั้นก่อนย้าย)

1. เปิดเว็บด้วยเบราว์เซอร์เครื่องเดิม → **ตั้งค่าแอดมิน** หรือ **เข้าสู่ระบบ** ด้วยบัญชีแอดมิน
2. หน้าแรกกด **ย้ายข้อมูลจากเครื่องนี้ขึ้นออนไลน์** (ทีม นักเตะ นัด และรูปการ์ด)
3. บัญชีผู้จัดการทีม/กรรมการต้องสร้างใหม่ในเมนูบัญชี › จัดการผู้ใช้ (บัญชีแบบเดิมย้ายไม่ได้ เพราะไม่ได้เก็บรหัสผ่านตัวจริงไว้)

### เพื่อนเข้าร่วม

1. แอดมินสร้างบัญชีให้ในเมนูบัญชี › จัดการผู้ใช้ แล้วบอกชื่อผู้ใช้กับรหัสผ่านเริ่มต้น
2. เพื่อนเปิดลิงก์เว็บ → **เข้าสู่ระบบ** → เปลี่ยนรหัสผ่านเองได้ในเมนูบัญชี

### ลืมรหัสผ่าน

- **ผู้จัดการทีม/กรรมการ**: ให้แอดมินลบบัญชีเดิม แล้วสร้างใหม่ด้วยชื่อผู้ใช้ใหม่ (ชื่อผู้ใช้เดิมใช้ซ้ำไม่ได้ และ Firebase ไม่ให้แอดมินตั้งรหัสแทนคนอื่นจากหน้าเว็บ)
- **เจ้าของลีก**: ใน Firebase console › Firestore Database › Data ลบเอกสาร `meta/owner` กับ `users/<uid ของคุณ>` แล้วไปที่ Authentication › Users ลบบัญชีเดิม จากนั้นเปิดเว็บ → **ตั้งค่าแอดมิน** ใหม่ (ข้อมูลลีกไม่หาย)

### ข้อมูลที่เก็บ

| ที่เก็บ | ข้อมูล | ใครอ่านได้ |
|---|---|---|
| `teams`, `matches` | ทีม นักเตะ แผน โปรแกรม ผลการแข่ง ผลงานนักเตะ | ทุกคน |
| `images` | รูปการ์ดนักเตะ (ชื่อเอกสาร = hash ของรูป) | ทุกคน |
| `users` | ชื่อ ชื่อผู้ใช้ บทบาท ทีมที่ดูแล (ไม่มีรหัสผ่าน) | เฉพาะคนที่มีบัญชีในลีก |
| `meta/owner` | เจ้าของลีก | ทุกคน |
| Firebase Authentication | รหัสผ่าน (ชื่อผู้ใช้แปลงเป็นอีเมลภายใน `<ชื่อผู้ใช้>@friends-league.example.com` ไม่มีการส่งอีเมลจริง) | ไม่มีใครเห็นรหัสผ่าน |

## วิธีรันบนเครื่อง

ไม่ต้อง build อะไร แต่ต้องเปิดผ่าน HTTP และต่ออินเทอร์เน็ต (โหลด React, Babel, Tailwind และฟอนต์จาก CDN)

1. เปิดโฟลเดอร์นี้ใน VS Code
2. คลิกขวาที่ `index.html` › **Open with Live Server**
3. เข้า `http://127.0.0.1:5500/index.html`

ถ้าดับเบิลคลิกเปิดไฟล์ตรง ๆ (`file://`) จะใช้ไม่ได้ เพราะ Babel ต้องโหลด `app.js` ผ่าน HTTP

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โหลด CDN และตั้งค่าสีของ Tailwind |
| `config.js` | ค่าตั้งค่า Firebase (`firebaseConfig`) · ว่างไว้ = โหมดเครื่องเดียว |
| `firestore.rules` | กฎความปลอดภัยของ Firestore (วางใน Firebase console) |
| `app.js` | โค้ด React ทั้งหมด (รันผ่าน Babel standalone) |
| `style.css` | ตัวแปรสีของธีม, ปุ่ม/แท็บเฉียง, ป้ายตำแหน่ง/การ์ด, สนาม, แอนิเมชัน |

ข้อควรระวังเวลาแก้โค้ด:

- ห้ามใส่ `import` / `export` ใน `app.js` ให้ใช้ `React` ที่เป็น global แทน
- ต้องล็อก Babel ไว้ที่ 7.x เพราะ Babel 8 จะแทรก `import` เข้ามาเอง ทำให้หน้าค้างที่ "กำลังโหลด…"
- ใช้ชื่อสีของธีม (`text-ink`, `bg-surface`, `text-accent` …) แทนการใส่รหัสสี hex ลงในคลาส

## ข้อจำกัด

- ถ้าไม่ใส่ค่า Firebase (โหมดเครื่องเดียว) ข้อมูลและรูปการ์ดจะอยู่แค่ในเบราว์เซอร์นั้น และระบบบัญชีกันได้แค่คนที่ยืมเครื่องไปแก้ผล
- แพ็กเกจฟรีของ Firebase อ่านข้อมูลได้ 50,000 ครั้ง/วัน และเขียนได้ 20,000 ครั้ง/วัน เพียงพอสำหรับลีกเพื่อน
- ถ้าสองคนแก้ทีมเดียวกันพร้อมกัน คนที่บันทึกทีหลังชนะ
