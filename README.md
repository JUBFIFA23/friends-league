# Friends League · eFootball 2027 Mobile

เว็บจัดทัวร์นาเมนต์ eFootball 2027 Mobile ระหว่างเพื่อน ๆ ใช้บันทึกผลการแข่ง ดูตารางคะแนนสด ดาวซัลโว และการ์ดทีมสไตล์การ์ดสะสม

ผลการแข่งต้องกรอกเอง เพราะ Konami ไม่มี API สำหรับดึงผล Custom Tournament

## ทำอะไรได้บ้าง

- **หน้าแรก**: นัดถัดไปพร้อมนับถอยหลัง, การ์ด 4 อันดับแรก (กรอบทอง/เงิน/ทองแดง) และผลล่าสุด
- **ตารางคะแนน**: ลูกศร ▲▼ บอกอันดับที่ขยับ และปุ่มแชร์ตารางเป็นรูป (ส่ง LINE ได้)
- **โปรแกรม/ผล**: จัดโปรแกรมพบกันหมดอัตโนมัติ (เลือกแบบเหย้า–เยือนได้), เลื่อนวัน/เวลาแข่ง และกรอกผลพร้อมคนยิง/แอสซิสต์/ใบเหลือง-แดง
- **ดาวซัลโว**: ตารางประตู แอสซิสต์ และใบเหลือง/แดง
- **ทีม**: การ์ดทีมแบบสะสม กดเพื่อดูโปรไฟล์ทีม (สถิติ ฟอร์ม คนยิง โปรแกรม)
- **ธีมสว่าง/มืด**: สลับได้ที่ปุ่มบนหัวเว็บ
- **Export / Import JSON**: สำรองข้อมูลลีก หรือย้ายข้อมูลไปเครื่องอื่น

## บัญชีและสิทธิ์

| บทบาท | ทำอะไรได้ |
|---|---|
| ผู้ชม (ไม่ล็อกอิน) | ดูทุกหน้า และ Export JSON |
| กรรมการ | กรอก/แก้ผลการแข่ง |
| แอดมิน | ทำได้ทุกอย่าง: จัดการทีม, จัดโปรแกรม, เลื่อนวัน, จัดการผู้ใช้, Import/รีเซ็ตข้อมูล |

- เปิดเว็บครั้งแรกในเบราว์เซอร์ไหน จะต้องสร้างบัญชีแอดมินคนแรกในเบราว์เซอร์นั้นก่อน จากนั้นแอดมินเพิ่มกรรมการได้ในเมนูบัญชี › จัดการผู้ใช้
- ไม่มีการเก็บรหัสผ่านตัวจริง เก็บแค่ค่า hash (SHA-256 + salt)
- **ข้อจำกัด**: ยังไม่มีเซิร์ฟเวอร์ บัญชีและข้อมูลลีกจึงอยู่ใน `localStorage` ของเบราว์เซอร์เครื่องนั้นเท่านั้น ไม่ซิงก์ข้ามเครื่อง ระบบนี้กันคนที่ยืมเครื่องไปแก้ผลได้ แต่ไม่ได้ปลอดภัยเท่าระบบที่มีเซิร์ฟเวอร์

## วิธีรัน

ไม่ต้อง build อะไร แต่ต้องเปิดผ่าน HTTP และต่ออินเทอร์เน็ต (โหลด React, Babel, Tailwind และฟอนต์จาก CDN)

1. เปิดโฟลเดอร์นี้ใน VS Code
2. คลิกขวาที่ `index.html` › **Open with Live Server**
3. เข้า `http://127.0.0.1:5500/index.html`

ถ้าดับเบิลคลิกเปิดไฟล์ตรง ๆ (`file://`) จะใช้ไม่ได้ เพราะ Babel ต้องโหลด `app.js` ผ่าน HTTP

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โหลด CDN, ตั้งค่าสีของ Tailwind, ตั้งธีมก่อนหน้าเว็บวาด |
| `app.js` | โค้ด React ทั้งหมด (รันผ่าน Babel standalone) |
| `style.css` | ตัวแปรสีของธีมสว่าง/มืด, การ์ด, แอนิเมชัน |

ข้อควรระวังเวลาแก้โค้ด:

- ห้ามใส่ `import` / `export` ใน `app.js` ให้ใช้ `React` ที่เป็น global แทน
- ต้องล็อก Babel ไว้ที่ 7.x เพราะ Babel 8 จะแทรก `import` เข้ามาเอง ทำให้หน้าค้างที่ "กำลังโหลด…"
- ใช้ชื่อสีของธีม (`text-ink`, `bg-surface`, `text-accent` …) ห้ามใส่รหัสสี hex ลงในคลาสตรง ๆ ไม่งั้นสลับธีมไม่ได้
